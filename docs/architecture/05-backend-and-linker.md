# 05 — Backend and Linker Architecture

## 1. Object File Emission

`ObjectEmitter` translates lowered `llvm::Module` instances into native machine code:
- Target triple: `x86_64-pc-windows-msvc`.
- Code generation options: `Reloc::PIC_`, `CodeGenOptLevel::Default` (optimized machine code).
- Emits native Windows COFF object files (`.obj`).
- Validated by checking the AMD64 COFF machine header (`0x8664`), guaranteeing compilation through genuine LLVM code generation rather than generated C++ transpilation.

## 2. Toolchain Discovery & Linking

`LinkerEnvironment` loads `toolchain/toolchain.json` (generated by `scripts/bootstrap.ps1` via `vswhere.exe`):
- Locates `lld-link.exe` (with fallback to MSVC `link.exe`).
- Discovers the MSVC toolset libraries directory (`VC\Tools\MSVC\<version>\lib\x64`).
- Discovers the Windows 10/11 SDK library directories (`ucrt\x64` and `um\x64`).
- Links against `nrqoba_runtime.lib` and CRT runtime libraries (`msvcrt.lib`, `ucrt.lib`, `vcruntime.lib`, `kernel32.lib`).
- Invokes the linker through `ProcessRunner` using Windows `CreateProcessW` with standard MSVC argument quoting rules for paths containing spaces.
